# 238. Product of Array Except Self

<details>
<summary>📝 Problem Statement</summary>

Given an integer array `nums`, return an array `answer` such that:

```text
answer[i] = product of every element except nums[i]
```

The solution must:

* Run in **`O(n)` time**
* **Not use division**
* The product of any prefix or suffix is guaranteed to fit in a 32-bit integer.

### Example 1

```text
Input:  nums = [1,2,3,4]
Output: [24,12,8,6]
```

### Example 2

```text
Input:  nums = [-1,1,0,-3,3]
Output: [0,0,9,0,0]
```

### Constraints

* `2 <= nums.length <= 10⁵`
* `-30 <= nums[i] <= 30`
* `answer[i]` is guaranteed to fit in a 32-bit integer.

</details>

<details>
<summary>🐢 Brute Force — Multiply Every Other Element</summary>

### Approach

For every index `i`, calculate the product of all elements except `nums[i]`.

So for every element, we traverse the entire array again and skip the current index.

### Code

```java
class Solution {

    public int[] productExceptSelf(int[] nums) {

        int n = nums.length;
        int[] result = new int[n];

        for (int i = 0; i < n; i++) {

            int product = 1;

            for (int j = 0; j < n; j++) {

                if (i != j) {
                    product *= nums[j];
                }
            }

            result[i] = product;
        }

        return result;
    }
}
```

### Complexity

* **Time:** `O(n²)`
* **Space:** `O(1)` extra space
  *(excluding the output array)*

</details>

<details>
<summary>⚡ Better Approach — Prefix and Suffix Products</summary>

### Intuition

For each index, we need the product of **everything except the current element**.

Instead of multiplying all the other elements again and again, divide them into two parts:

```text
Elements before i × Elements after i
```

For example:

```text
nums = [1, 2, 3, 4]
```

For index `2`:

```text
1 × 2 × 4 = 8
```

We can calculate this as:

```text
prefix product × suffix product
```

So for every index `i`:

```text
answer[i] =
product of elements before i
×
product of elements after i
```

### Prefix Product

For:

```text
[1, 2, 3, 4]
```

the prefix products we need are:

```text
[1, 1, 2, 6]
```

For example, at index `2`, the prefix product is:

```text
1 × 2 = 2
```

Notice that `nums[2]` itself is not included.

### Suffix Product

Similarly, the suffix products are:

```text
[24, 12, 4, 1]
```

For index `2`:

```text
4
```

because the elements after index `2` contain only `4`.

Therefore:

```text
answer[2] = 2 × 4 = 8
```

### Code

```java
class Solution {

    public int[] productExceptSelf(int[] nums) {

        int n = nums.length;

        int[] prefix = new int[n];
        int[] suffix = new int[n];
        int[] result = new int[n];

        // Product of elements before each index
        prefix[0] = 1;

        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] * nums[i - 1];
        }

        // Product of elements after each index
        suffix[n - 1] = 1;

        for (int i = n - 2; i >= 0; i--) {
            suffix[i] = suffix[i + 1] * nums[i + 1];
        }

        // Combine prefix and suffix products
        for (int i = 0; i < n; i++) {
            result[i] = prefix[i] * suffix[i];
        }

        return result;
    }
}
```

### Complexity

* **Time:** `O(n)`
* **Space:** `O(n)` extra space

</details>

<details>
<summary>🚀 Optimal Approach — Prefix + Suffix with O(1) Extra Space</summary>

### Intuition

The previous approach is already `O(n)` in time, but it uses two extra arrays:

```text
prefix[]
suffix[]
```

We can avoid them.

The important observation is:

> We don't actually need to store all prefix and suffix products at the same time.

We can calculate the prefix product **while traversing from left to right**.

But we still need the suffix product for every index.

So let's use the `result` array itself to temporarily store the suffix products.

### Step 1 — Store Suffix Products in `result`

First, traverse from **right to left**.

For every index `i`, store the product of all elements after `i` in `result[i]`.

For:

```text
nums = [1, 2, 3, 4]
```

we get:

```text
result = [24, 12, 4, 1]
```

At this point, `result[i]` contains:

```text
product of everything after i
```

### Step 2 — Add the Prefix Product

Now traverse from **left to right**.

Maintain a single variable:

```text
prefixProduct
```

which represents the product of everything before the current index.

For `nums = [1,2,3,4]`:

Initially:

```text
prefixProduct = 1
```

At index `0`:

```text
result[0] = 1 × 24 = 24
```

Then include `nums[0]` in the prefix:

```text
prefixProduct = 1
```

At index `1`:

```text
result[1] = 1 × 12 = 12
```

Then:

```text
prefixProduct = 1 × 2 = 2
```

At index `2`:

```text
result[2] = 2 × 4 = 8
```

And so on.

Thus, each position finally becomes:

```text
product before i × product after i
```

which is exactly the required answer.

### Algorithm

1. Create the `result` array.
2. Traverse from right to left and store suffix products in `result`.
3. Maintain a single `prefixProduct`.
4. Traverse from left to right:

   * Multiply the stored suffix product by `prefixProduct`.
   * Update `prefixProduct` using the current element.
5. Return `result`.

### Complexity

|              | Complexity         |
| ------------ | ------------------ |
| ⏱️ **Time**  | `O(n)`             |
| 💾 **Space** | `O(1)` extra space |

The output array does not count as extra space.

</details>

<details>
<summary>💻 Optimal Code</summary>

```java
class Solution {

    public int[] productExceptSelf(int[] nums) {

        int n = nums.length;
        int[] result = new int[n];

        // Store suffix products
        result[n - 1] = 1;

        for (int i = n - 2; i >= 0; i--) {
            result[i] = result[i + 1] * nums[i + 1];
        }

        // Add prefix products
        int prefixProduct = 1;

        for (int i = 0; i < n; i++) {

            result[i] *= prefixProduct;

            prefixProduct *= nums[i];
        }

        return result;
    }
}
```

</details>

<details>
<summary>💡 Why does this work with zeroes?</summary>

We never use division, so zero does not cause any special problem.

For example:

```text
nums = [-1, 1, 0, -3, 3]
```

At the index containing `0`, we multiply:

```text
product before 0 × product after 0
```

which gives:

```text
(-1 × 1) × (-3 × 3) = 9
```

For every other index, the product includes the `0`, so the result is `0`.

Therefore:

```text
[0, 0, 9, 0, 0]
```

The prefix/suffix approach naturally handles zeroes without any special case.

</details>

<details>
<summary>⚠️ Why can't we simply multiply everything and divide?</summary>

A tempting solution is:

```text
totalProduct = product of all elements

answer[i] = totalProduct / nums[i]
```

But the problem explicitly **does not allow division**.

There is also a problem when `nums[i] = 0`, because division by zero is not possible.

The prefix + suffix approach avoids both problems.

</details>

<details>
<summary>🧠 Pattern to Remember</summary>

When a problem asks for the result at every index using **all elements except the current one**, think about splitting the array around that index:

```text
                           i
                           ↓
[ elements before i ] [ nums[i] ] [ elements after i ]
        ↓                                  ↓
   Prefix Product                    Suffix Product
```

Therefore:

```text
answer[i] = prefixProduct × suffixProduct
```

For this problem, the key optimization is:

> **Use the output array to store one side of the information, and one variable to maintain the other side.**

This reduces the extra space from `O(n)` to **`O(1)`**.

</details>
